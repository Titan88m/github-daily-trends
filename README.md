# نبض گیت‌هاب — نسخه ۱

داشبورد موبایل‌محور فارسی و RTL برای رصد پروژه‌های برتر GitHub با ظاهر Dark AMOLED.

## قابلیت‌ها
- رتبه‌بندی جهانی و فارسی در سه بازه ۲۴ ساعت، ۷ روز و ۳۰ روز؛ ۲۰ پروژه در هر دسته.
- توضیح، زبان، تعداد ستاره کل، رشد ستاره و لینک مخزن.
- علامت قرمز برای مخزن‌هایی که در برداشت‌های روزانه قبلی دیده شده‌اند.
- Snapshot روزانه، تاریخچه آماری و نمودار ۱۴ برداشت اخیر.
- PWA قابل نصب روی Android.

## راه‌اندازی
1. این پروژه را در یک مخزن GitHub قرار دهید.
2. از مسیر **Settings → Pages**، گزینه **Deploy from a branch** و شاخه `main` / پوشه `/root` را انتخاب کنید.
3. در **Settings → Actions → General** اجازه نوشتن محتوا را برای workflow فعال کنید.
4. از تب Actions، گردش‌کار **Daily GitHub trends** را یک‌بار با `Run workflow` اجرا کنید.
5. صفحه GitHub Pages را باز کنید و در مرورگر Android گزینه Add to Home screen را بزنید.

گردش‌کار هر روز ساعت 04:17 UTC اجرا می‌شود و فایل‌های `data/latest.json` و `data/history.json` را commit می‌کند.

## دقت داده و محدودیت‌ها
- ۲۴ ساعت با Snapshotهای روزانه سنجیده می‌شود؛ دقت آن به زمان اجرای روزانه محدود است.
- رتبه‌بندی ۷ و ۳۰ روزه تا زمانی که Snapshot متناظر جمع شود، کامل نیست.
- پروژه‌های فارسی با وجود حروف فارسی در توضیح، نام یا README شناسایی می‌شوند؛ این یک طبقه‌بندی تقریبی است و ممکن است برخی پروژه‌های فارسی‌زبان را از دست بدهد.
- GitHub Search API سقف نتایج دارد؛ این نسخه اول یک فهرست کاندیدا از مخازن فعال با حداقل ستاره گردآوری می‌کند، نه کل GitHub.
- نشان قرمز یعنی مخزن در Snapshotهای قبلی دیده شده، نه الزاماً در هر گزارش روزانه قبلی رتبه گرفته باشد.
- GitHub Actions از `GITHUB_TOKEN` داخلی استفاده می‌کند؛ توکن شخصی لازم نیست.

## ساختار
- `index.html`, `styles.css`, `app.js`: رابط کاربری
- `fetch_trends.py`: جمع‌آوری داده و محاسبه رشد
- `.github/workflows/daily.yml`: اجرای زمان‌بندی‌شده
- `data/`: آخرین گزارش و تاریخچه
